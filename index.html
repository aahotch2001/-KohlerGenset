🧠 1. System Overview & Standalone Operation

This controller manages a Kohler 60kW Diesel Generator driven by a John Deere 4045T 4.5L Turbo Diesel Engine (converted for 120/240V Single-Phase Double-Delta residential operation).

24/7 Standalone Autonomy: The ELEGOO ESP32 controller mounted inside the generator cabinet runs 100% autonomously 24/7/365. It executes block heater thermostat protection, 12V battery charging, and safety monitoring with zero dependency on your phone or PC being turned on.

🌐 Networking & Hardwired Connection

  • Hardwired Cat6 Ethernet: Connects via W5500 SPI Ethernet module directly to the Solar Room network switch (100 Mbps, 0% packet loss through double steel enclosure).
  • Local Mosquitto Broker: 192.168.68.91:1883
  • Tailscale 5G Remote IP: 100.108.173.127:1883
  • Direct ESP32 IP: 192.168.68.199:1883

🧮 3. Calibrated Sensor Formulas & Dual ADS1115 ADCs

ADS1115 Module #1 (I2C Address 0x48 - ADDR Pin to GND):

A0 (Oil Pressure Sender Terminal S): Blue Wire via 10k/22k divider + 0.1uF capacitor Formula: (volts0 - 0.5) * (100.0 / 4.0) [PSI] A1 (Water Temp Sender Terminal S): Purple Wire via 10k/22k divider + 0.1uF capacitor Formula: 240.0 - (volts1 * 49.0) [Inverse Kohler NTC: Cold=40°F, Warm=129°F] A2 (12V Starter Battery Voltage): Green/Yellow Wire via 10k/2.2k divider Formula: volts2 * 7.450 [Calibrated for 13.70V actual multimeter reading] A3 (48V Solar Battery Bank): Black/Orange Wire via single 47k/2.7k divider Formula: volts3 * 18.407 [Calibrated for 49.7k/2.7k divider]

ADS1115 Module #2 (I2C Address 0x49 - ADDR Pin to 3V3):

A0 (5 PSI Hydrostatic Fuel Level Transducer): Yellow Wire (0.5V-4.5V Direct Input - 0 Resistors!) Formula: ((fuelVolts - 0.5) / 4.0) * 100.0 [% Tank Level] Real-Time Burn Rate: Calculates 1-minute rolling GPH from hydrostatic pressure drop.

🛡️ 4. Control Rules & Failsafe Protections

  • 15-Second Over-Crank Safety: If starter cranks > 15 seconds without Alternator Terminal W detecting RPM > 400, the ESP32 disengages Relay 1 to prevent starter burnout.
  • 120V Coolant Block Heater Thermostat: Driven by 3-wire digital thermometer on Pin D25. Turns ON Relay 2 when block temp drops ≤ 38°F, and turns OFF at 50°F (max 120m limit).
  • Victron 48V-to-12V Smart Charger: Direct 3.3V control on Pin D4 to Victron Remote Pin H. Turns ON when 12V battery ≤ 12.2V DC, and turns OFF at 13.8V DC (0mA 48V standby power drain!).
  • Smart 12V Battery Health Rating: Measures 500A cranking voltage sag ($V_{\text{min}}$) ➔ Rates battery HEALTHY (≥10V), FAIR (9V-10V), or WEAK (<9V).
  • Smart Adaptive Telemetry Rate: 10-second interval when stopped (99% packet/battery saver < 0.1%/day) ➔ 1-second interval when running/cranking.

📱 6. Phone App Top-Bar Indicator Lights Guide

The top bar header features 3 real-time status indicator badges:

  • CHARGER ON / CHARGER OFF — Green when Victron 12V charger is active; Red when OFF (0mA standby).
  • PUMP ON / PUMP OFF — Orange when circulation pump/heater is active; Blue when idle.
